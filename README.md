# Hausman Klimabonus-Rechner

Testversion des Förderrechners für Wärmepumpen in Luxemburg (Klimabonus Wunnen 2026–2030).

**Online testen:** https://dannyclees.github.io/hausman-klimabonus-rechner/

- `index.html` – eigenständige Seite mit dem Rechner
- `foerderrechner.js` – das Widget (kann auch in eine Website eingebettet werden)

Hinweis: In dieser Testversion werden eingegebene E-Mail-Adressen nicht gespeichert.
Alle Beträge sind unverbindliche Maximalwerte.
